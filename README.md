    "# Word2Vec Training and Visualization (Text8)\n",
    "\n",
    "## 📌 Project Description\n",
    "\n",
    "This project trains a Word2Vec model using the Text8 dataset and visualizes word embeddings in 2D space using PCA.\n",
    "\n",
    "The goals are:\n",
    "\n",
    "* Understand how Word2Vec learns semantic relationships between words\n",
    "* Observe clustering behavior of similar words (e.g., king/queen, man/woman)\n",
    "* Evaluate embedding quality through visualization\n",
    "\n",
    "---\n",
    "\n",
    "## 📂 Dataset\n",
    "\n",
    "We use the **Text8 dataset**, which is a cleaned Wikipedia text corpus.\n",
    "\n",
    "### Preprocessing\n",
    "\n",
    "* The entire text is split into words\n",
    "* Every 100 words are grouped into a \"sentence\"\n",
    "\n",
    "---\n",
    "\n",
    "## ⚙️ Methodology\n",
    "\n",
    "### 1. Data Preparation\n",
    "\n",
    "* Load raw text\n",
    "* Split into tokens\n",
    "* Create pseudo-sentences (100 words each)\n",
    "\n",
    "### 2. Model Training\n",
    "\n",
    "We train a Word2Vec model with the following parameters:\n",
    "\n",
    "* `vector_size = 100`\n",
    "* `window = 10`\n",
    "* `min_count = 1`\n",
    "* `workers = 4`\n",
    "\n",
    "### 3. Word Selection\n",
    "\n",
    "You can select representative words you want(for example):\n",
    "\n",
    "* **Royalty**: king, queen, prince, princess\n",
    "* **Gender**: man, woman\n",
    "* **Animals**: dog, cat\n",
    "* **Fruits**: apple, orange\n",
    "\n",
    "### 4. Dimensionality Reduction\n",
    "\n",
    "* Apply PCA to reduce embeddings from 100D to 2D\n",
    "\n",
    "### 5. Visualization\n",
    "\n",
    "* Use matplotlib to generate a scatter plot\n",
    "* Each word is labeled in the 2D space\n",
    "\n",
    "---\n",
    "\n",
    "## 📊 Expected Results\n",
    "\n",
    "* Words with similar meanings should cluster together:\n",
    "\n",
    "  * king ↔ queen\n",
    "  * man ↔ woman\n",
    "  * dog ↔ cat\n",
    "\n",
    "* If the model is well-trained:\n",
    "\n",
    "  * Semantic relationships should be preserved\n",
    "\n",
    "Example:\n",
    "\n",
    "```\n",
    "king - man + woman ≈ queen\n",
    "```\n",
    "\n",
    "---\n",
    "\n",
    "## 🚀 How to Run\n",
    "\n",
    "1. Prepare the dataset:\n",
    "\n",
    "```\n",
    "text8.txt\n",
    "```\n",
    "\n",
    "2. Run the script:\n",
    "\n",
    "```bash\n",
    "python word2vec.py\n",
    "```\n",
    "\n",
    "3. Output:\n",
    "\n",
    "* A 2D scatter plot of selected word embeddings\n",
    "\n",
